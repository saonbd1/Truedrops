# AirdropHunter

A crypto airdrop listing website built with TanStack Start and Tailwind CSS, deployed on Netlify.

## What It Does

Displays a curated list of crypto airdrops with filtering, search, and sorting. Each airdrop card shows the estimated value, requirements, participant count, deadline, difficulty, and direct links to claim.

## Key Technologies

- **TanStack Start** — file-based routing with React 19
- **Tailwind CSS v4** — utility-first styling
- **Lucide React** — icon library
- **Netlify** — hosting and deployment

## Running Locally

```bash
npm install
npm run dev
```

The dev server starts at [http://localhost:3000](http://localhost:3000).

For Netlify feature emulation (edge functions, forms, etc.):

```bash
netlify dev
```

This starts a local server at [http://localhost:8888](http://localhost:8888).
